 1. Purpose
 MED-01 defines how SOPHIX receives raw usage records from external usage platforms, normalizes them into a common
 usage format, deduplicates them, quarantines invalid records, reconciles source totals, and emits trusted mediated usage
 records for rating.

 The first required use case is voice CDR mediation from VoipSwitch or another SIP/voice platform.

 MED-01 is the step before usage rating:
             Voice platform CDR
               -> MED-01 normalize/deduplicate/quarantine
               -> RAT-01 rate and charge
               -> BIL-05 wallet debit or BIL-01/BIL-02 postpaid charge

 candidate, or rating-required, but monetary rating belongs to RAT-01.

 5. Core Concepts
 5.1 Usage Source
 A usage source is an external platform that produces usage records.

 Examples:

   - VOIPSWITCH_KE

   - SIP_PLATFORM_NRB

   - future TV pay-per-view usage source

   - future data usage platform

 5.2 Raw CDR
 A raw CDR is the original provider/source record stored with minimal transformation.

 Raw CDRs must be retained for audit and reprocessing.

 5.3 Mediated Usage Record
 A mediated usage record is the canonical cleaned record consumed by RAT-01.

 Example:
           {
               "mediatedUsageId": "med-20260602-000001",
               "operatorCode": "WIK",
               "usageType": "VOICE_CALL",
               "subscriptionId": "SUB-700045",
               "serviceRef": "svc_VOIP_STD",
               "callingNumberNormalized": "+254700111222",
               "calledNumberNormalized": "+254711222333",
               "callStartedAt": "2026-06-02T10:15:00+03:00",
               "durationSeconds": 75,
               "sourceRecordId": "VS-CDR-998877",
               "mediationStatus": "READY_FOR_RATING"
           }


 5.4 Quarantine
 Quarantine is the operational queue for records that cannot safely be mediated or rated.

 Examples:

   - missing subscription mapping;

   - invalid timestamp;

   - negative duration;

   - missing called number;

   - duplicate conflict;

   - unsupported usage type.

 7. Business Rules
  Rule ID                                    Rule                                                    Notes

  R-MED-01                                   Every imported CDR must be stored as raw data           Prevents source data loss.
                                             before normalization.

  R-MED-02                                   Every raw CDR must have a deterministic dedupe          Source id if stable, otherwise normalized field hash.
                                             hash.

  R-MED-03                                   Duplicate exact records are ignored after first         No double rating.
                                             successful mediation.

  R-MED-04                                   Duplicate hash with conflicting payload is              Human review required.
                                             quarantined as DUPLICATE_CONFLICT.

  R-MED-05                                   Missing required fields are quarantined, not            Data quality traceability.
                                             dropped.

  R-MED-06                                   Records with unresolved subscription/customer are       RAT-01 needs a billable target.
                                             quarantined.

  R-MED-07                                   Zero-duration calls can be mediated only if source      Avoid false chargeable records.
                                             disposition indicates answer or regulatory reason.

  R-MED-08                                   Failed calls are not sent for rating unless product     Default no rating.
                                             policy explicitly rates them.

  R-MED-09                                   Number normalization must be deterministic and          Kenya first, future regions configurable.
                                             operator-aware.

  R-MED-10                                   Source batch reconciliation must compare source         Operational control.
                                             count/duration to stored/mediated/quarantined
                                             totals.

  R-MED-11                                   Manual repair must preserve original raw payload        Audit.
                                             and record user id.

  R-MED-12                                   Mediated records are immutable after emitted.           Avoid silent billing changes.
                                             Corrections create adjustment/reversal flow in
                                             RAT-01.

 11. Frontend Usage
 FE-APP-01 Backoffice uses MED-01 for:

   - Usage source configuration.

   - Batch import dashboard.

   - Raw batch detail and import counts.

   - Quarantine queue.

   - Repair and replay actions.

   - Reconciliation run status.

   - Deep link from customer/subscription to mediated usage history.

 Self-care should not read MED-01 directly. Customer-visible usage history should come from RAT-01 or a reporting/read API
 after records are rated and safe to display.

 14. Testing Requirements
 14.1 Unit Tests
   - Parse VoipSwitch CDR row.

   - Normalize local Kenya MSISDN to E.164.

   - Build deterministic record hash.

   - Reject missing called number.

   - Reject negative duration.

   - Quarantine unresolved subscription.

   - Exact duplicate does not create second mediated record.

   - Duplicate conflict creates quarantine.

 14.2 Integration Tests
   - Import file creates batch and raw records.

   - Mediation worker creates mediated records.

   - UsageMediated event is emitted.

   - Quarantine repair and replay creates mediated record.

   - Batch reconciliation totals match imported rows.


SOPHIX BSS Design Documents                                                                                              Page 9
 14.3 End To End Tests With RAT-01
   - Raw answered voice CDR becomes mediated usage and is rated by RAT-01.

   - Failed call is not sent to rating by default.

   - Unknown subscription stays quarantined until repaired.

   - Duplicate CDR is not rated twice.



 15. Definition Of Done
 MED-01 is complete when:

   - Usage source configuration exists.

   - Raw CDR batches can be imported from at least one source mode.

   - Raw CDR rows are stored before processing.

   - Normalization creates canonical mediated usage records.

   - Dedupe prevents double mediation.

   - Invalid records go to quarantine.

   - Repair and replay works.

   - UsageMediated events are consumed by RAT-01.

   - Reconciliation compares source, stored, mediated, and quarantined totals.

   - Backoffice can inspect batches and quarantine.
