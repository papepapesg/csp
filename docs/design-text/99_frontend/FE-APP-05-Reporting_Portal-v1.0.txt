 1. Purpose
 FE-APP-05 defines the management reporting user experience for SOPHIX BSS.

 The portal gives managers, supervisors, finance, commercial operations, network operations, field operations, and executives
 a controlled way to view dashboards, drill into KPIs, schedule exports, and inspect reconciliation exceptions.

 The portal is Kenya/WIK-first but must remain operator-configurable for other regions: language, currency, timezone, brand,
 KPI labels, dashboard visibility, fiscal calendar, export formats, and data access rules.

 FE-APP-05 consumes REP-01 dashboard/export APIs. It does not query operational module databases directly.



 2. Application Placement
 For a budget-conscious medium deployment, start FE-APP-05 inside the Backoffice shell as a Reporting area. Split it into a
 separate portal only when reporting users, permission scope, dashboard volume, or export scheduling justify a separate
 deployment.

 8. UX Requirements
   - Use dense dashboard layouts, not marketing-style cards.

   - Every dashboard must show data freshness and filter scope.

   - Every KPI with a number must have a clear definition tooltip.

   - Every chart must support table view for auditability.

   - Export buttons must show permission and row-limit warnings.

   - Drilldown links must say which module owns the record.

   - Empty states must distinguish no data, no permission, and data delay.

 11. Test Scenarios
   1. User sees only allowed dashboards.

   2. Dashboard data is loaded only from REP-01.

   3. Finance export respects row-level filters.

   4. Drilldown opens Backoffice record with owning module route.

   6. No permission and no data render different states.

   7. Export download is audited.
