 1. What this flow is
 KE WIK's BPMN composes framework workers to migrate a subscription from source HomePass + source Package to target
 HomePass + target Package, atomically, while keeping the customer ACTIVE on source until target activation succeeds.

 The flow shape mirrors RELOCATION FLOW-WIK v1.1 — request validation, scheduled-wait timer, billing intent with
 cycle-anchor handling, pay-first gate, source suspend, source HomePass release, physical work (SHIFTING WO or
 self-move), target activate, MODIFY_SERVICE diff dispatch, target HomePass claim, master fields commit, state flip, event
 emission, notification.

 Two flow-specific additions versus RELOCATION:

   1. The billing intent is MIGRATION_INTENT with cycleAnchorPolicy in context. BIL-01 v1.1 may return up to 4 line items
     (MIGRATION_FEE, signed MIGRATION_PRORATE_DELTA for PRESERVE, or OLD_CYCLE_CREDIT +
     FIRST_CYCLE_CHARGE for RESET, plus optional EQUIPMENT_REPLACEMENT_FEE).

   2. After target ACTIVATE_SERVICE succeeds, the BPMN dispatches FUL-03 v1.1's MODIFY_SERVICE with diff between
     source and target Package compositions. FUL-03 fans out per-service-class add/drop/modify calls to provisioners. This
     step handles the Package-tier change at the target (e.g., adding IPTV service class, dropping a service class, modifying
     speed/voice profiles).
