 1. Goal
 Implement network field audits without duplicating RLM, WO, or provisioning ownership.

 FA-02 stores audit tasks, expected snapshots, observations, discrepancies, and routing. RLM-CFG-01 remains the source of
 truth for HomePass/topology, WO-01 handles dispatch, and PROV-INT provides network read/check data.



 2. Runtime Flow

               MOB->>FA: submit GPS/photos/measurements

               FA->>FA: compare expected vs observed
               FA->>FA: run Drools severity/routing
               FA->>APR: approval if sellability/topology correction needs it
               FA->>RLM: request approved correction

 FA-02 behavior:

   1. Validate permission through EM-CFG-03.

   2. Apply idempotency by key and request hash.

   3. Insert task in CREATED.

   4. Call RLM-CFG-01 to fetch expected network state.

   5. Optionally call PROV-INT read APIs for signal/port state.

   6. Insert network_field_audit_expected_state rows.

   7. If createWorkOrder=true, create WO.

   8. Emit NetworkFieldAuditTaskCreated.

 7. Step 5 - Submit And Compare
 Endpoint:
           POST /api/network-field-audits/tasks/nfat-001/submit

 Comparison:

   1. Load expected snapshots.

   2. Load observations.

   3. Detect MISSING_NODE, WRONG_GPS, LOW_SIGNAL, PORT_MISMATCH, NOT_SERVICEABLE, or UNDOCUMENTED_PLANT.

   4. Create discrepancies.

   5. If none, close task.

   6. If any, run routing.



 8. Step 6 - Drools
 Fact:
           public record NetworkFieldAuditFact(
                String operatorCode,
                String discrepancyType,
                String technologyFamily,
                boolean homepassSellable,
                int usablePortCount,
                double rxPowerDbm,
                String proposedSellability
           ) {}

 Rules:
           package rules.field_audit.network.severity

           rule "No usable port on sellable HomePass"
           when
             $f : NetworkFieldAuditFact(discrepancyType == "PORT_MISMATCH",
                                        homepassSellable == true,
                                        usablePortCount == 0)
             $d : NetworkFieldAuditDecision()
           then
             $d.setSeverity("HIGH");
             $d.route("REQUEST_RLM_CORRECTION");
           end

           package rules.field_audit.network.approval

           rule "Sellability downgrade requires approval"
           when
             $f : NetworkFieldAuditFact(proposedSellability == "NOT_SELLABLE")
             $d : NetworkFieldAuditDecision()
           then
             $d.requireApproval("NETWORK_FIELD_AUDIT_SELLABILITY_CHANGE");
           end

 10. Tests
   1. Create task freezes RLM snapshot.

   2. Duplicate task request returns same task.

   3. WO creation carries correct origin context.

   4. Observation idempotency works offline.

   5. Port mismatch opens discrepancy.

   6. Sellability correction requires EM-CFG-04 when configured.

   7. RLM is called only through API, not local DB writes.
