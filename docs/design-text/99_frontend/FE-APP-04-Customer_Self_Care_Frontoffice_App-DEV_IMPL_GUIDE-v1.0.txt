 DEV_IMPL_GUIDE - FE-APP-04 Customer Self-Care
 Frontoffice App
 1. Implementation Objective
 Implement the customer self-care app for customer profile visibility, subscription summary, invoices, wallet/payment, support
 tickets, notification preferences, and allowed self-service actions.

 Read these first:

 3. Build Order
   1. Implement login/account binding and customer profile read.

   2. Implement active subscription summary from SUB-LM.

   3. Implement invoice list/detail/PDF through billing read/file APIs.

   4. Implement balance/wallet/payment status through BIL/PAY-GW.

   5. Implement ticket creation/status through TCK/ASR types.

   6. Implement notification preferences through NOT.

   7. Add limited self-service commands only when owning SUB-WF APIs are enabled.


 4. MVP Scope
 First release: profile, subscription summary, invoices, payment status/instructions, ticket create/status, preferences. Defer
 complex package changes, relocation, migration, and advanced Customer 360 detail.


 5. Tests
   - Customer sees own data only.

   - Invoice PDF authorization.

   - Payment status refresh.

   - Ticket creation idempotency.

   - Partial module outage.

   - Logout clears local cache.
