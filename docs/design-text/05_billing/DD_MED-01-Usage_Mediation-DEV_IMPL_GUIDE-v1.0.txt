 1. How To Read This Guide
 This guide follows the execution flow from source configuration to raw import, mediation, quarantine repair, and handoff to
 rating.

 MED-01 does not rate usage and does not debit wallets. It produces clean usage records for RAT-01.

 Create a usage source for VoipSwitch Kenya.

 Meaning:

   - timezone is used when source timestamps do not include an offset.

   - secret_ref points to SFTP/API credentials.

 5. Step 4 - Store Raw CDR Rows
 For each parsed row, build a deterministic record_hash.

 Recommended hash input for VoipSwitch:
          source_code + cdr_id

 If source CDR id is missing:
          source_code + caller + callee + start_time + duration_sec + sip_account

 Insert raw row:
          insert into raw_usage_record (
             raw_record_id,
             batch_id,
             usage_source_id,
             operator_code,
             source_record_id,
             source_sequence_no,
             record_hash,
             raw_payload_json,
             processing_status,
             created_at
          ) values (
             'rur-20260602-000001',
             'rub-20260602-1000',
             'usrc-voipswitch-ke',
             'WIK',
             'VS-CDR-998877',
             1,
             'sha256:def456',
             '{"cdr_id":"VS-CDR-998877","caller":"0700111222","callee":"0711222333","start_time":"2026-06-02 10:15:00","duration_sec"
             'NEW',
             now()
          );

 Do not normalize first and store later. Raw row storage comes first.



 6. Step 5 - Normalize Raw CDR

SOPHIX BSS Design Documents                                                                                               Page 2
 The mediation worker loads unprocessed rows:
          select *
          from raw_usage_record
          where processing_status = 'NEW'
          order by created_at asc
          limit 500;

 For each row:

   1. Parse source payload by source type.

   2. Normalize caller and callee.

   3. Parse timestamps using source timezone.

   4. Validate duration.

   5. Resolve subscription/customer/service.

   6. Create mediated record or quarantine.

 Pseudo-code:
          public function mediateRawRecord(RawUsageRecord $raw): void
          {
              $source = $this->sources->find($raw->usage_source_id);
              $parsed = $this->parserRegistry->for($source->source_type)->parse($raw->raw_payload_json);

               $normalized = $this->normalizer->normalizeVoiceCdr($source, $parsed);
               $validation = $this->validator->validate($normalized);

               if (!$validation->ok()) {
                   $this->quarantine($raw, $validation->reasonCode(), $validation->details());
                   return;
               }

               $mapping = $this->subscriptionResolver->resolveBySipAccountOrNumber(
                   $raw->operator_code,
                   $normalized->sipAccount,
                   $normalized->callingNumberNormalized,
                   $normalized->callStartedAt
               );

               if (!$mapping) {
                   $this->quarantine($raw, 'SUBSCRIPTION_NOT_FOUND', $normalized->toArray());
                   return;
               }

               $this->createMediatedUsage($raw, $normalized, $mapping);
          }




 7. Step 6 - Normalize Numbers
 For WIK Kenya, local mobile number:
          0700111222 -> +254700111222
          0711222333 -> +254711222333

 Emergency numbers remain short:
          999 -> 999
          112 -> 112

 Implementation rule:

   - Keep national short codes unchanged if configured as short-code prefixes.

   - Convert local MSISDNs to E.164.

   - Strip spaces, dashes, and brackets.

   - Reject impossible numbers into quarantine.

 10. Step 9 - Handle Duplicates
 If inserting raw row violates unique (usage_source_id, record_hash), load the existing row.

 If raw payload is identical:
          update raw_usage_record
          set processing_status = 'DUPLICATE',
              processed_at = now()
          where raw_record_id = 'new-row-id';

 Do not create another mediated record.

 If hash matches but payload differs, quarantine:
          reason_code = DUPLICATE_CONFLICT

 This indicates source data changed for the same CDR identity.

 MED-01 must:

   1. Store repair payload and user id.

   2. Re-run validation using repair values.

   3. Create mediated usage if valid.

   4. Mark quarantine RESOLVED.

   5. Emit UsageMediationReplayed.

 Do not overwrite the original raw payload.



 13. Step 12 - Mark Rating Handoff
 When RAT-01 accepts the mediated record, update:
          POST /api/usage-mediation/records/med-20260602-000001/mark-sent-to-rating

          {
              "ratingRequestId": "ratreq-001"
          }

 After rating succeeds:
          POST /api/usage-mediation/records/med-20260602-000001/mark-rated

          {
              "ratedUsageId": "rated-20260602-000001"
          }

 This lets Backoffice trace a raw CDR to mediated record to rated usage.

 15. Suggested Worker Commands
 These are Laravel commands or queue jobs and can be consolidated into shared billing workers.
           med:pull-source-files --source=VOIPSWITCH_KE
           med:import-batch --batch=rub-20260602-1000
           med:process-raw-records
           med:reconcile-batch --batch=rub-20260602-1000
           med:replay-quarantine --quarantine=mq-20260602-000001
           med:close-stale-batches

 Recommended schedule:

  Command                                                           Frequency

  med:pull-source-files                                             Every 5-15 minutes, depending source availability.

  med:process-raw-records                                           Continuous queue worker or every minute.

  med:reconcile-batch                                               After batch processing, plus nightly.

  med:close-stale-batches                                           Hourly.

  med:replay-quarantine                                             Manual or event-driven after repair.




 16. Error Codes
  Error code                                                        Meaning

  MED_SOURCE_INACTIVE                                               Usage source is not active.

  MED_BATCH_DUPLICATE                                               Same source file/checksum already imported.

  MED_PARSE_FAILED                                                  Source row cannot be parsed.

  MED_REQUIRED_FIELD_MISSING                                        Required CDR field missing.

  MED_INVALID_TIMESTAMP                                             Timestamp cannot be parsed.

  MED_INVALID_DURATION                                              Duration is negative or inconsistent.

  MED_NUMBER_NORMALIZATION_FAILED                                   Caller/callee cannot be normalized.

  MED_SUBSCRIPTION_NOT_FOUND                                        No billable subscription mapping found.

  MED_DUPLICATE_CONFLICT                                            Same CDR identity with conflicting payload.

  MED_UNSUPPORTED_DISPOSITION                                       Source disposition should not be mediated.

 18. Test Scenarios
 18.1 Valid Answered CDR
 Input:

   - Caller 0700111222.

   - Callee 0711222333.

   - Duration 75.

   - Subscription mapping exists.

 Expected:

   - Raw row stored.

   - Mediated record created.

   - Event UsageMediated.

 18.2 Duplicate CDR
 Input:

   - Same cdr_id imported twice.

 Expected:

   - One mediated record.

   - Duplicate raw row marked DUPLICATE or duplicate import rejected.

 18.3 Duplicate Conflict
 Input:

   - Same cdr_id, different duration.

 Expected:

   - Quarantine with DUPLICATE_CONFLICT.

   - No second mediated record.

 18.4 Unknown Subscription
 Input:

   - SIP account not mapped.

 Expected:

   - Quarantine SUBSCRIPTION_NOT_FOUND.

   - Repair can replay with subscription id.

 19. Developer Checklist
 Before marking MED-01 complete:

   - Raw records are stored before processing.

   - Duplicate handling prevents double mediation.

   - Number normalization is deterministic.

   - Subscription resolver supports historical lookup.

   - Quarantine preserves original raw payload.

   - Repair stores user id and notes.

   - Mediated record has enough fields for RAT-01.

   - UsageMediated event is emitted once per mediated record.

   - Batch reconciliation is visible to Backoffice.

   - MED-01 does not calculate monetary charges.
