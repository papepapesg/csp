 1. How To Read This Guide
 Promotional campaign is a commercial eligibility and redemption flow.

 SIP-05 decides whether a lead/customer/order can receive a campaign offer. If the offer is a discount, SIP-05 calls SIP-03 to
 create the discount assignment. Billing application happens later in DIS-OP/BIL.

 6. Step 5 - Validate Campaign
 Run:
           POST /api/promotional-campaigns/camp-001/validate

 Implementation checks:

   1. Dates are valid.

   2. At least one active offer exists.

   3. Discount/bundle/package refs exist and are active.

   4. At least one channel exists.

   5. Target rules have valid syntax and known reference types.

   6. Budget and participant caps are valid.

   7. Approval policy is resolved.

 If validation passes:
           update promotion_campaign
           set status = 'READY_FOR_REVIEW',
               updated_at = now()
           where campaign_id = 'camp-001'
             and status = 'DRAFT';

 Sales app calls:
          POST /api/promotional-campaigns/eligibility
          Content-Type: application/json

          {
              "operatorCode": "WIK",
              "channelCode": "SALES_APP",
              "leadId": "lead-001",
              "orderId": "ORD-1001",
              "customerId": "CUS-100045",
              "packageRef": "pkg-fiber-100m",
              "bundleCode": "FIBER_TV_STARTER",
              "franchiseId": "fr_01J_NRB_002",
              "homepassId": "HP-001",
              "onDate": "2026-07-02"
          }

 Backend finds active campaigns:
          select c.*
          from promotion_campaign c
          join promotion_campaign_channel ch on ch.campaign_id = c.campaign_id
          where c.operator_code = 'WIK'
            and c.status = 'ACTIVE'
            and c.start_date <= date '2026-07-02'
            and c.end_date >= date '2026-07-02'

 11. Step 10 - Pause Or End Campaign
 Pause:
          POST /api/promotional-campaigns/camp-001/pause
          Content-Type: application/json

          {
              "reasonCode": "BUDGET_REVIEW"
          }

 Patch:
          update promotion_campaign
          set status = 'PAUSED',
              updated_at = now()
          where campaign_id = 'camp-001'
            and status = 'ACTIVE';

 End:
          update promotion_campaign
          set status = 'ENDED',
              updated_at = now()
          where campaign_id = 'camp-001'
            and status in ('ACTIVE', 'PAUSED', 'APPROVED')
            and end_date < current_date;

 Existing participation remains auditable. New eligibility must exclude PAUSED and ENDED.



 12. Drools Rule Samples
 Campaign eligibility should be server-side and can use Drools for configurable targeting.
          package rules.commercial.campaign

          rule "Acquisition campaign requires sales app channel and matching franchise"
          when
            $ctx : CampaignContextFact(channelCode == "SALES_APP", franchiseAllowed == true, packageAllowed == true)
            $camp : CampaignFact(campaignType == "ACQUISITION", status == "ACTIVE")
            $out : CampaignEligibilityDecision()
          then
            $out.addEligibleCampaign($camp.getCampaignCode());
          end

          rule "Cap reached blocks redemption"
          when
            $camp : CampaignFact(capReached == true)
            $out : CampaignRedemptionDecision()
          then
            $out.reject("CAMP_CAP_REACHED");
          end

          rule "Campaign with budget and discount offer requires finance approval"
          when
            $camp : CampaignFact(hasDiscountOffer == true, budgetLimitAmount > 0)
            $out : CampaignApprovalDecision()
          then
            $out.setApprovalRequired(true);
            $out.setApprovalPolicyCode("CAMPAIGN_COMMERCIAL_FINANCE");
          end

 13. Suggested Worker Commands
          campaign:activate-due
          campaign:end-due
          campaign:cap-sync
          campaign:eligibility-cache-refresh
          campaign:stuck-redemption-retry

  Command                                                      Purpose

  campaign:activate-due                                        Activates approved campaigns whose start date has arrived.

  campaign:end-due                                             Ends campaigns past end date.

  campaign:cap-sync                                            Recalculates participant/budget counters.

  campaign:eligibility-cache-refresh                           Refreshes active campaign read model by channel/franchise.

  campaign:stuck-redemption-retry                              Retries SIP-03 assignment call for selected participation without assignment id.




 14. Error Codes
  Code                                                         Meaning

  CAMP_CODE_DUPLICATE                                          Campaign code already exists.

  CAMP_INVALID_DATE_RANGE                                      Start/end dates invalid.

  CAMP_EMPTY_OFFER                                             Campaign has no active offer.

  CAMP_DISCOUNT_NOT_ACTIVE                                     Discount offer is inactive/retired.

  CAMP_BUNDLE_NOT_ACTIVE                                       Bundle offer is inactive/unavailable.

  CAMP_CHANNEL_NOT_ALLOWED                                     Channel is not configured for campaign.

  CAMP_NOT_ELIGIBLE                                            Context failed target rules.

  CAMP_CAP_REACHED                                             Participant or budget cap reached.

  CAMP_DUPLICATE_PARTICIPATION                                 Participant already selected/redeemed campaign.

  CAMP_ASSIGNMENT_FAILED                                       SIP-03 assignment call failed.

  CAMP_APPROVAL_REQUIRED                                       Campaign cannot activate before EM-CFG-04 approval.

  CAMP_APPROVAL_REQUEST_FAILED                                 EM-CFG-04 approval request failed.

 16. Test Scenarios
 16.1 Acquisition Campaign Redeem
   - Campaign active for SALES_APP.

   - Lead/order matches franchise and package.

   - Eligibility returns campaign.

   - Redeem creates participation.

   - SIP-03 assignment is created.

 16.2 Wrong Franchise Rejected
   - Campaign targets fr_01J_NRB_002.

   - Request has fr_01J_NRB_999.

   - Eligibility excludes campaign with reason FRANCHISE_NOT_ELIGIBLE.

 16.3 Cap Reached
   - maxParticipants = 1000.

   - 1000 redeemed rows exist.

   - Next redeem returns 409 CAMP_CAP_REACHED.

 16.4 Paused Campaign
   - Campaign status PAUSED.

   - Eligibility does not return it.

   - Existing participations remain visible in reports.

 16.5 SIP-03 Failure
   - Redeem participation created.

   - SIP-03 assignment fails transiently.

   - Participation remains SELECTED.

   - Worker retries using same idempotency key.



 17. Developer Checklist
   - Campaign eligibility is server-side.

   - Sales app does not decide campaign eligibility offline.

   - Campaign redeem is idempotent per participant.

   - Discount redemption calls SIP-03 assignment API.

   - Campaign approval is configured/executed in EM-CFG-04.

   - Drools covers configurable eligibility/redemption/approval decisions.

   - No invoice/wallet amount is applied in SIP-05.

   - Caps and channel restrictions are enforced.

   - Events feed reporting and cache refresh.
